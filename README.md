# Octopi My Heart

A puzzle game where you bring two octopi together, but your path secretly draws a message.

## Gameplay

- Use **arrow keys** to move
- Reach **Octopus A** (blue), then **Octopus B** (purple), then the **Exit**
- Complete before the timer runs out!

## The Secret

Your movement path traces a hidden message that's revealed when you complete the level.

## How to Play

1. Open `index.html` in a web browser
2. Use arrow keys to navigate
3. Collect both octopi and reach the exit before time runs out

## Technical Details

- HTML5 Canvas rendering
- Grid-based movement system
- Path recording and replay
- Timer-based challenge

## Development

No build process required. Just open `index.html` in a browser.
